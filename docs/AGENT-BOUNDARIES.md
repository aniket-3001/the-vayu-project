# What the AI may and may not do

Vayu Air uses AI in one place that visitors can reach: the assistant. This page says what it can do, what it cannot, the limits on it, and which test fails if a limit breaks.
The numbers below are held in one place in the code, `ASSISTANT_LIMITS` in `apps/api/src/assistantAgent.ts`, and a test checks that this page's promises are in the instructions the model is given.

## The rule

**Code decides. AI only words things.**
Every answer about the air, a walk, school, masks, windows, alerts or fires is worked out by fixed rules in `packages/core/src/assistantRules.ts` from numbers we already have. The model is allowed to say the same answer in kinder words. It is never asked for a fact, a number or a decision.

## What the assistant can do

| It can                                                         | How                                                                                                                                                                                    |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Answer a question the rules cover, in friendly words           | The rules answer first. The model may reword that answer.                                                                                                                              |
| Answer a question the rules do not cover, from the facts given | The model is given only the facts in the request (place, AQI, level, PM2.5, GRAP stage, alerts, fire count, the people's ages and day type, and the best hour) and fixed instructions. |
| Fall back to the rules' own answer, with the same numbers      | Whenever the model is off, slow, over a limit, or fails a check.                                                                                                                       |

## What it cannot do

| It cannot                                                    | Why it cannot                                                                                                                                                                                                 |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Take any action: send, change, save, delete or call anything | It has no tools. It is a single text-in, text-out call. Logging a walk ("Asha walked in the park for 40 minutes") is matched by plain patterns in the app and saved on the device; the model is not involved. |
| Say a number that is not in the facts                        | Every number in a reworded or grounded answer is compared with the rules' answer and the facts. One that is not there sends the plain answer instead.                                                         |
| See a name or a place                                        | Names and the place are replaced with placeholders before the model is called and put back afterwards. A placeholder the model invents sends the plain answer instead.                                        |
| Drop a safety word                                           | If the rules' answer says "unofficial", "official", "112", "N95" or "FFP2", or names an official source, the reworded answer must too.                                                                        |
| Say a school is closed                                       | A reply that says so is refused.                                                                                                                                                                              |
| State a GRAP stage as official                               | If the model mentions GRAP without saying it is our estimate, "our estimate, not an official order" is added.                                                                                                 |
| Give medical advice                                          | The guardrail denies the topic, and the standing instructions say to name the air and suggest a doctor.                                                                                                       |
| Include a link, a tag or markup                              | Such a reply is refused.                                                                                                                                                                                      |
| Be talked out of its rules                                   | The caller's words are data inside `QUESTION`. An instruction hidden in a question does not change the number check, which is code. The guardrail also blocks prompt attacks on input.                        |
| Remember anything                                            | Nothing is stored about a question. The context is sent with each request.                                                                                                                                    |

## The limits

| Limit                                   | Value                                                                                                                                                      | Where                                                              |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Question length                         | 300 characters                                                                                                                                             | the request contract                                               |
| Answer length                           | 600 characters, and a reworded answer may not be more than 1.5 times the original plus 60 characters                                                       | `assistantAgent.ts`                                                |
| Tokens the model may write              | 220                                                                                                                                                        | every model call                                                   |
| Time to wait for the model              | 6 seconds, then the plain answer goes out                                                                                                                  | `ASSISTANT_LIMITS.modelTimeoutMs`                                  |
| Questions per caller per day            | 40                                                                                                                                                         | DynamoDB, one conditional update per call; a day is a day in India |
| Questions for the whole service per day | 500                                                                                                                                                        | the same                                                           |
| Request-form submissions                | 5 per caller per day, 200 in all                                                                                                                           | the same                                                           |
| Request rate                            | 3 a second (burst 6) for the assistant, 1 a second (burst 3) for the form, 25 (burst 50) for everything else                                               | API Gateway stage settings                                         |
| Models                                  | one: Amazon Nova Micro through its Asia Pacific inference profile; the stack's permission names that profile and that model only                           | `infra/lib/Assistant.ts`                                           |
| Guardrail                               | one: blocks hate, insults, sexual content, violence, misconduct and prompt attacks (input), a medical-advice topic, and emails, card numbers and passwords | `infra/lib/Assistant.ts`                                           |
| Kill switch                             | SSM parameter `/vayu/assistant/enabled`; the model is called only while it is exactly `true`; if it cannot be read, the model is off                       | `killSwitch.ts`                                                    |

## What happens when a limit is hit

The app does not break. The assistant says why in the small print under its answer (switched off, reached its limit, had a problem, could not be reached) and gives the rules' answer, with the same numbers.

## A real example of a boundary doing its job

On 10 October 2026, the first deploy of the assistant answered every question from the rules alone. The cause: the guardrail's prompt-attack filter was blocking our own rewording instruction, which sat in the user turn, and the code fell back to the rules, as designed. The fix moved the instruction into the system prompt, which the filter does not read as an attack. The same check then let a reworded answer through, and an "ignore your rules" question still fell back to the rules. Nothing a visitor saw was ever wrong during this.

A property test found a second gap the same day: a masked name's placeholder number (`[person 1]`) counted as an allowed number, so a model could have slipped an invented "1" past the check. Placeholders are no longer counted as numbers.

## The other uses of AI

| Use                                                                                            | State                                                                                              |
| ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Alert wording (Bedrock, same number check)                                                     | Built and tested. Live scheduled sends are off.                                                    |
| Hindi voice note (Polly)                                                                       | Built and tested; off by default. The IAM permission is not in the stack unless it is switched on. |
| Everything else in the app (the exposure dial, the tasks, the alerts strip, the Lens, the map) | No AI. Fixed rules and arithmetic.                                                                 |

## Cost of the AI

A question costs about $0.0008, nearly all of it the guardrail. At the daily limit of 500 questions that is about $0.41 a day, at most about $12 to $13 a month. `docs/cost.md` has the priced figures and how they are worked out.
