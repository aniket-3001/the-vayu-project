# Safety rules

Each rule is a thing the app must never do, where the code stops it, and the test that fails if it happens.
The rule names (I1 to I17) are the ones in the playbook. Test names are quoted from the code, so you can search for them.

How to check them all: `make prove` (lint, types, every test, `cdk synth`, and a check that the deployed bundle holds no prototype code).
`make smoke LIVE_URL=<address>` runs the data rules against the live site.

## What is not proven

- The purifier is not built. Rules I13 and I16 apply to it and are not tested on a device.
- The measuring unit has not been compared with a monitor over days, so its accuracy is unknown; it is labelled as a low-cost sensor.
- Telegram alerts are built and tested against fakes. Live scheduled sends are off, and no real chat has been sent a scheduled alert.
- Bluetooth has been seen working from Chrome on a Mac; Android Chrome has not been tried.
- The tests run against fakes and fixtures. The smoke test is the live check, and it was run against the deployed site on 11 October 2026.
