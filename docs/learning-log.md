# What broke, and how it was fixed

Each entry is something found by running the system for real, not by reading code. They are the "what we learned" of the
project. Entries are in the order they were found; the dates are 10 and 11 October 2026.

| What broke                                                                              | How it was found                                                        | The fix                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| The API answered 403 behind CloudFront                                                  | First live call                                                         | The viewer's `Host` header was forwarded to API Gateway. The origin request policy now forwards only the viewer address.                                                                                                                                                                                                                                                                                                                                                                                                       |
| The assistant never used the model                                                      | First live question: "Wording by AI" never appeared                     | Bedrock's guardrail has a prompt-attack filter that blocked our own rewording instruction in the user turn. The instruction moved to the system prompt.                                                                                                                                                                                                                                                                                                                                                                        |
| A masked name counted as a number                                                       | The number check let `[person 1]` through as the allowed figure 1       | A masked name no longer counts as a number; a test holds it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| "No reading right now" on three places                                                  | The first live walk                                                     | The regional model's answer left out the hour in progress. It is kept now, and an estimate is cached one minute, not five.                                                                                                                                                                                                                                                                                                                                                                                                     |
| The map's monitor job timed out and was rate-limited                                    | The first complete run                                                  | It waits as long as OpenAQ asks (up to three times), spaces its requests, and stops at a time budget inside the function's limit.                                                                                                                                                                                                                                                                                                                                                                                              |
| The first deploy failed, and the rollback failed too                                    | `cdk deploy`                                                            | An API stage setting named a route before it existed. The stage now waits for its routes.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| OpenAQ rejected our key (401) late on 10 October                                        | The stations job returned nothing                                       | A new key was put in Secrets Manager (from the clipboard, never typed in chat); the job read 7,268 monitors. The map falls back to the regional model and says so if it happens again.                                                                                                                                                                                                                                                                                                                                         |
| The wind stopped, then came back patchy                                                 | Opening the map many times                                              | Open-Meteo counts each point of a request as a call against the address's daily allowance. The wind and the air model are now asked once for everyone by our API and kept; MET Norway is the second source; a failed fetch is retried no sooner than ten minutes and the old answer is served.                                                                                                                                                                                                                                 |
| Speech stopped after the first answer                                                   | Using the voice                                                         | A per-caller daily quota (3,000 characters) was used up and the API answered 429. The limits were raised (12,000 a caller, 60,000 in all) and the page now says when it cannot speak. Separately, Chrome drops speech started right after a cancel, so there is a 60 ms gap.                                                                                                                                                                                                                                                   |
| Hindi answers were machine-flavoured                                                    | Reading them                                                            | The Hindi answers are now fixed wording written and read through by a person, with the facts slotted in; the model is never called for Hindi.                                                                                                                                                                                                                                                                                                                                                                                  |
| The recorded days showed absurd spikes                                                  | Reading the archive for 22 Dec, 23 Jan and 30 Mar                       | One monitor read 999 (the feed's "out of range") and others spiked alone. Two rules drop them and the count is written into the file; nothing else is changed.                                                                                                                                                                                                                                                                                                                                                                 |
| A blog screenshot said AQI 500 beside "GRAP Stage II"                                   | Reading my own screenshot, then every recorded day's text on every page | The stage was taken from the last 24 hours the monitor had, not the last 24 hours, so gaps pulled in older, cleaner hours; and PM10 was stretched, from one hour's ratio however large, over the whole day. It is now the last 24 hours, with that ratio capped at 2, checked against the monitors' own PM10 on 24 station-days: 22 landed in the same stage as the monitor's own index and 2 had no estimate (too few recent hours). The alert says "the last 24 hours average AQI N" and says when this hour alone is worse. |
| Rain was sold as clean air when the forecast showed none                                | The same audit, 23 Jan and 7 Oct                                        | The rain alert promised cleaner air whatever the day's forecast said. It now says plainly when the forecast for the day is no cleaner than now.                                                                                                                                                                                                                                                                                                                                                                                |
| A model answer said "[Place] has good air quality" at AQI 61                            | A script driving the live site in a browser, 12 Oct                     | The model capitalised the masked-name placeholder, so it was not put back; and it called a Moderate level "good", which no number check can catch. Placeholders are now put back in any case, and an answer that calls the air good or clean when the level is not Good is refused.                                                                                                                                                                                                                                            |
| A logged walk read "from 00:50"                                                         | The same run                                                            | One message used a 24-hour time while the rest of the app uses am and pm. It now says 12:50 am.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| A judge read the README as "live, seen working" and found the checklist mostly unticked | An independent review, 12 Oct                                           | The checklist described an older UI and many rows had never been run. It was rewritten as a current-state list and the unticked rows that can be run in a browser were run; what needs a real phone is listed as not checked.                                                                                                                                                                                                                                                                                                  |
| Common questions went to the wrong answer                                               | A review that ran the shipped patterns, 12 Oct                          | "kid wear a mask" hit the school rule, "urban" hit "ban", and "aaj bahar jaana theek hai" matched nothing. Whole words, specific rules first, Hinglish added, each phrase a test.                                                                                                                                                                                                                                                                                                                                              |
| The request form promised a reply that nobody sends                                     | The same review                                                         | The words now say it is saved, kept 180 days, and no one is notified automatically.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Archive file names broke the parser                                                     | The archive's CSV                                                       | Station names contain commas, so the splitter honours quotes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| The Devices card's chart was a black line                                               | A screenshot of the real unit's card                                    | Seven styles were never written. They are now, and the chart was rebuilt as a live AQI chart in the level colours.                                                                                                                                                                                                                                                                                                                                                                                                             |
| The measuring unit showed "no reading" once connected                                   | The app, then the serial log                                            | The sensor read fine until the app connected, then every read failed ("No more data in frame"): the sensor had stopped measuring, most likely a power dip when Bluetooth connected. The firmware now starts the sensor again when the app connects and whenever three reads in a row fail.                                                                                                                                                                                                                                     |
| The first firmware did not match the wiring                                             | Reading the board's own sketch                                          | It assumed I2C on an ESP32 DevKit; the board is an ESP32-S3 wired over UART. It was rewritten for the real wiring and compiled and run.                                                                                                                                                                                                                                                                                                                                                                                        |
