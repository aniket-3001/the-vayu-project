The whole product runs as one AWS CDK stack (TypeScript) in Mumbai (ap-south-1), and every Lambda runs on Graviton (arm64). The browser never calls an air-data provider: readings, forecasts and fire data come through my API, so keys, caching and spending limits live in one place. The API fetches public air data, applies fixed rules, and returns one answer with its source and age.

**AWS open source**

- **AWS CDK (TypeScript):** the whole stack, from CloudFront to Step Functions. CDK assertion tests turn safety rules into failing builds before anything deploys: every Lambda on arm64, no function time limit over 2 minutes, every bucket blocks public access, only the account route sits behind a token, and no secret value in an environment variable.
- **Powertools for AWS Lambda (Logger, Tracer):** structured JSON logs, and an X-Ray trace of every AWS call (DynamoDB, Bedrock, Polly, Systems Manager), so a slow request shows which call was slow.

**AWS services, and why each one**

- **Amazon CloudFront + Amazon S3 (private bucket):** the app and the API share one address, so there is no CORS. Hashed asset files are cached for a year and the page itself never is. The API sets `cache-control` on each answer and CloudFront keeps it at most 15 minutes; an answer without that header, such as an error, is never kept. A repeat lookup returns from CloudFront in about 0.15 s. A fresh one spends a median 1.5 s in Lambda (p99 5.2 s), because it fetches live from OpenAQ.
- **Amazon API Gateway (HTTP API) + AWS Lambda** (Node 22, Graviton, 256 MB): one function serves every `/v1` route. Each request is validated against a schema on arrival and each answer before it leaves, so a malformed answer becomes an error, never a number on screen. Throttle: 25 requests a second (burst 50); 3 for the assistant and speech; 1 for the request form.
- **Amazon DynamoDB** (on-demand, TTL), three tables. Cache: the scheduled jobs' snapshots. Watch: saved accounts, the daily quota counters and cached Polly audio. Rooms: device readings. Each quota is one conditional `UpdateItem` that adds one only if the counter is below the limit (40 per caller, 500 in all), so two simultaneous requests cannot both take the last slot. No lock. TTL deletes old counters.
- **Amazon EventBridge Scheduler:** every 15 minutes a Lambda refreshes four reference places so the first visitor is served from cache; every 30 minutes another reads about 7,200 monitors for the map. Retries are zero on both, so a failed run waits for the next slot instead of piling up. CloudWatch alarms fire if the first job goes 45 minutes without running, or the second 90, with missing data treated as breaching, so a silent stop is caught.
- **Amazon Bedrock (Nova Micro) with Guardrails**, through the `apac.` inference profile. Fixed rules decide the advice. The model is given the rules' answer and the facts, and may reword it or answer a question no rule covers from those facts alone. Code then checks every number it wrote against the facts; on any mismatch, or a guardrail block, a 6-second timeout or any error, the rules' own text goes out. Temperature 0.2, 220 output tokens at most. The Guardrail filters hate, violence and prompt attacks on input, and denies medical-advice topics.
- **Amazon Polly (neural voice Kajal):** reads answers aloud in English and Hindi. Audio is cached in DynamoDB by its text, so a repeated answer costs nothing. Limits: 400 characters a request, 12,000 a caller a day, 60,000 in all.
- **Amazon Cognito + API Gateway JWT authorizer:** accounts are optional. Email and password go straight from the browser to Cognito, so my API never sees a password. The authorizer checks the token on the one account route, and saved places and family are keyed by the user id inside the verified token.
- **AWS Secrets Manager:** five secrets (OpenAQ key, NASA FIRMS key, Telegram bot token, a webhook secret and a request salt). The Lambdas hold only references, never the values.
- **AWS Systems Manager Parameter Store:** one parameter is the model's kill switch. It must read exactly "true"; anything else, or a failed read, turns the model off. One command stops all model spend within a minute, with no deploy.
- **AWS Step Functions:** an alert loop that sends a message, waits for a tap with a task token, reminds and escalates, and a workflow that checks whether a room's air improved after a cleaner went on. Both are deployed and tested against fakes; live sends are switched off.
- **Amazon CloudWatch, Amazon SNS, AWS X-Ray:** 8 alarms (API errors, API 5xx, harvest errors, harvest stopped, stations stopped, device ingest errors, alert send errors, alert loop failed), a dashboard, and traces on every function. The SNS topic has no subscriber yet.
- **AWS IoT Core, Amazon Data Firehose, Amazon S3, Amazon Athena:** a device-to-cloud telemetry path, built and tested but not in use, because the unit talks to the phone over Bluetooth. Athena queries are capped at 1 GB scanned.

**Cost.** About $4.50 a month idle, from AWS list prices, not a bill. An assistant question costs about $0.0008, and 98% of that is the guardrail, so the caps sit on the assistant. With every cap reached it is about $46 a month. A flood aimed at CloudFront itself is not capped; there is no WAF.
